# Pack Plan (local staging)

A free public budget tool by Ravenous Wolves. This is a **local staging** copy for review. Nothing here has been pushed, deployed, or published.

- Data stays in the browser under the `rwBudget.v1` key. First run is blank.
- The only outside network calls are Google Fonts (Inter and Teko).
- `https://DOMAIN/pack-plan/` in the canonical, Open Graph, robots, and sitemap files is a placeholder. Replace `DOMAIN` with the real host at launch; the `/pack-plan/` path slug stays.
- Export and Import JSON backups are in Settings (`pack-plan-backup-YYYY-MM-DD.json`).

Not financial advice.
